# Veer AI Editor Rebuild：Open Design 原型

原生重建（`native/macos-editor`）的 UI 蓝图。由 Open Design 0.24.1（本机 Claude Code 作为设计代理）根据
[`docs/VEER_AI_EDITOR_OPENDESIGN_BRIEF_2026-10-17.md`](../../docs/VEER_AI_EDITOR_OPENDESIGN_BRIEF_2026-10-17.md) 生成。

- Open Design 项目 ID：`veer-ai-editor-rebuild-20261017`
- 文件：`veer-editor.html`（单文件，约 1,490 行，所有数据模拟，无网络请求）
- 工具栏右侧的“演示状态”下拉可切换 11 个状态；主流程可真实点击：试用示例配置 → 出口确认 → 示例指令 → 生成中 → 待审阅 → 切换接受 → 写入 → 撤销 → 导出

直接用浏览器打开 `veer-editor.html` 即可预览。

## 原生实现采纳了什么

- 三栏结构：会话侧栏、单列对话、可收起的检查器（变更 / 规则 / 测试 / 出口）。
- 绿色用户气泡；处理步骤折叠为“处理完成 · 4 步 · 秒数”。
- 每项修改独立成卡片，带接受开关；被替换的规则以红色代码片段显示。
- 胶囊形校验徽标；“查看差异”“查看发送给 AI 的内容”为同一行的文字链接。
- 输入框内左侧为解析方式胶囊，右侧为隐私提示与发送按钮。
- 出口确认页的警告用琥珀色横幅。

## 有意不同的地方

- 检查器标签用原生分段控件，而不是网页式下划线标签。
- 原型的“演示状态”下拉不进入产品；原生版的状态由真实流程产生。
- 设置使用 macOS 原生设置窗口（⌘,），而不是原型里的 sheet。
