# Open Design 简报：Veer · AI Editor Rebuild

依据：`docs/VEER_AI_EDITOR_SPEC_2026-10-17.md`。本简报交给 Open Design 生成 UI 原型。

## 交付

新建项目 **Veer · AI Editor Rebuild**，产出一个可交互的高保真 macOS 桌面应用原型 `veer-editor.html`（单文件 HTML/CSS/JS）。它是原生 SwiftUI 实现的视觉蓝图，不是生产代码。所有数据模拟，禁止任何网络请求、真实 API、密钥、遥测。界面语言简体中文。画布 1320 × 860，同时检查 960 × 640（最小窗口）。提供浅色与深色（跟随 prefers-color-scheme，并有手动切换）。

## 产品一句话

Veer AI Editor 让你用一句话修改 Mihomo 分流规则，每一处改动先给你看清楚，再由你决定写不写。配置在本机解析，AI 只收到匿名出口与指令。它不启动 VPN、不测速、不切换运行中的节点。

## 视觉方向

- 像一个真正的 macOS 26 应用：系统字体（-apple-system / SF Pro）、SF Mono 等宽、窗口红绿灯、原生风格工具栏与侧栏、SF Symbols 风格的统一线性图标（可用内联 SVG 近似）。
- 清晰、安静、可靠、轻量。系统语义中性色；Veer 绿色（浅色约 #1F9D55，深色提亮）只用于主要操作、选中、已写入等小面积。
- 层级靠底色明度差 + 1px 分隔线，不堆阴影、不用大面积渐变、不做营销式 hero、不做装饰性指标卡。
- Liquid Glass 只出现在操作层：主要按钮（导入、写入草稿、发送）、输入框外框、浮动“回到最新”、toast。用半透明填充 + backdrop blur + 细高光边近似；正文、规则、差异一律实底、可选中。提供减少透明度时的实底回退。
- 4pt 网格间距（2/4/8/12/16/24/32/48），圆角 6/10/16/pill。对话阅读轨道最大宽 760。单屏不超过 4 个字号层级。
- 状态永远“图标 + 文字”，颜色不是唯一线索：通过=绿、未验证/警告=琥珀、失败=红、信息=蓝。

## 窗口结构

三栏：左侧栏（约 240）｜主区对话｜右侧检查器（约 340，可收起）。窗口工具栏（与红绿灯同一行）：侧栏开关、会话标题 + 副标题（如“草稿 · 2 项未导出修改”）、撤销、重做、导出、检查器开关。不要在内容区再放一条重复的标题栏。

### 侧栏

- 顶部“新建导入”按钮。
- 会话列表（每次导入是一个会话）：标题（文件名或订阅主机名）、副行（来源 · 时间）、有未导出修改时显示绿色圆点。搜索框。
- 底部：设置入口；一行隐私说明“配置在本机解析 · AI 只收到匿名出口”。
- 模拟会话：`我的配置.yaml`（当前，有修改）、`sub.example.net`、`work-office.yaml`。

## 必须做出的屏幕与状态（用顶部的演示切换器或左下角“演示状态”菜单在它们之间跳转，同时主流程可真实点击）

1. **开始页**（无会话）：中央 Veer 标识、标题“用一句话修改分流规则”、说明；主要按钮“导入配置文件”（玻璃突出），次要“粘贴 YAML”“订阅链接”“试用示例配置”。整个区域是拖放目标（演示拖入悬停态）。底部隐私说明。订阅链接以 sheet 输入，含导入中与失败（“链接返回了重定向，Veer 不会自动跟随” + 重试）状态。
2. **出口确认**（导入后）：“识别到 7 个出口 · 2 个未指定地区”；列表行：出口名、类型标签（策略组/节点）、地区下拉（推断值或“未指定”）。内联警告“配置没有 MATCH 兜底规则”。说明“地区为推断或声明，未实测”。主要按钮“开始编辑”，次要“稍后”。模拟出口：🇯🇵 日本出口（策略组·日本）、🇺🇸 美国出口（策略组·美国）、🇭🇰 香港出口（策略组·香港）、自动选择（策略组·未指定）、一个超长名称“Premium-SG-Netflix-Unlock-IEPL-02-高速专线”（节点·新加坡）、Backup Relay（节点·未指定）、DIRECT、REJECT。
3. **对话 · 空**：消息区显示 4 个示例指令芯片（“Netflix 走日本，ChatGPT 走美国”“YouTube 走香港”“example.com 直连”“屏蔽广告”）。
4. **对话 · 生成中**：用户气泡（右侧）“Netflix 走日本，ChatGPT 走美国”；助手处理步骤（真实任务状态，不是模型推理）：理解指令 ✓ → 检查出口 ✓ → 生成修改（进行中）→ 校验（等待）。带“停止”按钮。
5. **对话 · 待审阅**（核心屏幕）：步骤折叠为“处理完成 · 4 步 · 2.4 秒”（可展开）；摘要“准备了 2 项分流修改，等待你确认。”；修改项列表，每项一行：
   - `Netflix → 日本出口（日本·推断）`，副行 `规则集 MetaCubeX geosite/netflix · 地址已验证`，右侧接受开关。
   - `ChatGPT → 美国出口（美国·推断）`，副行 `规则集 MetaCubeX geosite/openai · 地址已验证`，替换提示“替换：DOMAIN-SUFFIX,openai.com,DIRECT”。
   - 校验徽标“已通过 Mihomo 配置测试 · 网络可达性未验证”。
   - 主要按钮“写入草稿 ⌘⇧↩”，次要“放弃”；文字链接“查看差异”“查看发送给 AI 的内容”。
   - 关掉一项开关后，摘要与按钮变为“写入 1 项”。
6. **对话 · 已写入**：该回合按钮替换为“已写入草稿”状态 + “撤销”；toast“已写入草稿，尚未导出”。工具栏副标题更新。
7. **查看发送给 AI 的内容**（展开面板或 sheet）：显示匿名化 payload：出口表 `出口1（日本）、出口2（美国）…`、指令“Netflix 走出口1（日本），ChatGPT 走出口2（美国）”，以及说明“未发送：节点地址、密码、订阅链接、现有规则”。
8. **对话 · 澄清**：用户“YouTube 走代理”→ 助手普通段落“请告诉我 YouTube 走哪个出口。”+ 快捷回复芯片（日本出口、美国出口、香港出口）。不是错误样式。
9. **对话 · 超出范围**：用户“节点太卡了换一个”→ 助手说明“我只编辑分流规则，不能测速或切换运行中的节点。你可以指定一个出口，例如‘YouTube 走香港’。”
10. **对话 · 错误**：AI 请求失败（HTTP 401）→ 说明 + 恢复按钮“打开设置”“改用本地解析”“重试”。另一个变体：校验失败（红色徽标 + 脱敏的内核输出摘要），写入按钮禁用并说明原因。
11. **输入框**：底部固定，玻璃外框，自动增高；左下模式切换“AI · deepseek-chat”/“本地解析”；右下发送按钮（生成中变停止）。占位“描述分流，例如“Netflix 走日本，ChatGPT 走美国””，下方细字“请勿粘贴密钥或订阅链接”。演示 `@` 补全弹层（出口名 + 地区 + 类型）和 `/` 命令弹层（/test、/undo、/export、/rules）。
12. **检查器四个标签**（分段控件：变更 / 规则 / 测试 / 出口）：
    - 变更：统一差异，SF Mono、行号、`+`/`−` 前缀 + 低饱和底色，未改动区折叠“… 18 行未改动”；顶部切换“本轮候选 / 相对原始配置”。内容包括新增 rule-providers（netflix、openai）与 rules 顶部两条 RULE-SET 规则、删除 openai.com 那条旧规则。
    - 规则：草稿 rules 全表（序号、类型、匹配、出口），筛选框，本次新增行有“新增”标记，RULE-SET 行可展开看 URL。
    - 测试：输入 `www.netflix.com` → 结果“需要内核数据：第 1 条 RULE-SET,netflix 可能命中（已跳过）”，以及按本地可判定规则落到“第 9 条 MATCH → 自动选择”。另一个例子 `example.com` → “第 3 条 DOMAIN-SUFFIX,example.com → DIRECT”。
    - 出口：出口列表与地区编辑。
13. **设置**（模态窗口或 sheet，macOS 设置窗口样式，顶部分段：AI / 隐私 / 校验）：AI 服务预设下拉（OpenAI、DeepSeek、OpenRouter、Ollama 本机、自定义）、Base URL、模型、API Key（安全输入，“已保存到钥匙串”状态）、“测试连接”及成功/失败结果；隐私页解释发送内容；校验页显示“内置 Mihomo（Veer mirror v1.19.29）· 可用”和“导出前默认校验”开关。
14. **导出确认**：sheet“导出完整配置副本”，显示“相对原始配置：+4 行 / −1 行，新增 2 个规则集”，“导出前进行内核校验”勾选，按钮“导出…”/“取消”；说明“不会覆盖原文件”。

## 模拟配置（用于差异与规则表）

```yaml
mixed-port: 7890
mode: rule
proxies: [ …节点已省略… ]
proxy-groups: [ …省略… ]
rule-providers:
  netflix: { type: http, behavior: domain, format: mrs, url: https://raw.githubusercontent.com/MetaCubeX/meta-rules-dat/meta/geo/geosite/netflix.mrs, path: ./rule_provider/netflix.mrs, interval: 86400 }   # 新增
  openai: { … geosite/openai.mrs … }   # 新增
rules:
  - RULE-SET,netflix,日本出口        # 新增
  - RULE-SET,openai,美国出口         # 新增
  - DOMAIN-SUFFIX,openai.com,DIRECT # 删除
  - DOMAIN-SUFFIX,example.com,DIRECT
  - DOMAIN-KEYWORD,google,美国出口
  - DOMAIN-SUFFIX,github.com,自动选择
  - GEOSITE,cn,DIRECT
  - GEOIP,CN,DIRECT,no-resolve
  - IP-CIDR,192.168.0.0/16,DIRECT,no-resolve
  - MATCH,自动选择
```

## 交互要求

- 主流程可点击：开始页“试用示例配置”→ 出口确认 →“开始编辑”→ 点击示例芯片 → 生成中（约 2 秒，可停止）→ 待审阅 → 切换开关 → 写入 → 撤销/重做（工具栏）→ 导出 sheet。
- 草稿变化后，未写入的旧候选显示“已失效 · 草稿已变化，请重新生成”，按钮不可用。
- 检查器可收起；窄窗口（< 1100）时检查器作为覆盖层浮在对话上方。
- 所有图标按钮有 title 提示与 aria-label；键盘可操作；`prefers-reduced-motion` 时取消动画；`prefers-reduced-transparency` 时玻璃变实底。

## 不要

- 不要连接按钮、流量图、延迟数字、节点健康度。
- 不要声称“连接成功”“已解锁”“最快”。
- 不要全屏玻璃、霓虹、渐变背景、emoji 当图标（国旗 emoji 只作为出口名的一部分出现）。
- 不要把每段内容都套成同等大圆角卡片。
